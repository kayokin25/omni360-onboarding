# Развёртывание

1. Задеплойте эту папку как сайт на Netlify (drag-and-drop, `netlify deploy`, или подключите к git-репозиторию — как удобнее). `netlify.toml` уже настроен: билд сам прогонит `npm run build:content`, который пересобирает `content/course-data.js` из `onboarding-omni360.html`.
2. Убедитесь, что на сайте включён **Netlify Blobs** — на большинстве планов это по умолчанию, ничего вручную включать не нужно.
3. **Один раз** после первого деплоя получите свою ссылку руководителя:
   ```
   curl -X POST https://<ваш-сайт>.netlify.app/api/bootstrap-manager \
     -H "content-type: application/json" \
     -d '{"name":"Ваше Имя"}'
   ```
   Ответ отдаст `token` — ваша ссылка: `https://<ваш-сайт>.netlify.app/manager.html?t=<token>`. Сохраните её, это единственный вход в дашборд руководителя. Повторно `bootstrap-manager` не сработает, как только в системе появится хотя бы один человек (специально, чтобы этим нельзя было создать себе лишний доступ позже).
4. В дашборде руководителя — поле «Добавить ученика»: вводите имя, получаете персональную ссылку, отправляете её ученику любым способом (чат, почта).

## Локальная разработка

```
npm install
npm run build:content   # перегенерировать content/course-data.js после правок onboarding-omni360.html
npx netlify dev
```

Без привязки к реальному Netlify-сайту (`netlify link`) Blobs локально не работают — функции будут отвечать 500. Для проверки вёрстки и интерактива без бэкенда откройте `index.html?t=x&mock=student` или `manager.html?t=x&mock=manager` — `js/mock.js` подставит тестовые данные вместо `/api/*` (активируется только при `?mock=...`, в реальной работе не используется).

## Если нужно поменять скриншоты

Исходники как сняты лежат в `assets/screenshots/_raw/`. То, что реально показывается в курсе, лежит в `assets/screenshots/` и генерируется:

```
npm run build:screenshots
```

Скрипт `scripts/build-screenshots.mjs` обрезает каждый скрин до той области, о которой говорит текст, и рисует оранжевую обводку там, где подпись ссылается на конкретный элемент. Рецепты — в объекте `SHOTS` в начале файла, координаты заданы долями (0..1), поэтому переснятый скрин другого размера обычно не требует пересчёта.

Чтобы заменить скрин: положите новый файл в `_raw/` под тем же именем, прогоните скрипт, посмотрите результат. Чтобы добавить новый — добавьте файл в `_raw/`, запись в `SHOTS`, тег `<img class="shotimg">` в `onboarding-omni360.html` и прогоните `npm run build:screenshots && npm run build:content`.

Скриншоты в курсе кликабельны: по клику открывается полный размер (обработчик — в `js/app.js` и в скрипте внутри `onboarding-omni360.html`).

## Если нужно поменять текст курса

Правьте `onboarding-omni360.html` как обычно (это по-прежнему единственный источник контента) и прогоните `npm run build:content` — изменения попадут в `content/course-data.js`, который использует само приложение. `onboarding-omni360.html` как самостоятельная страница тоже продолжает открываться и работать (справочный вариант на один экран).
